\## 📌 About The Project



\*\*RailTrack\*\* is a web-based Indian Railway train tracking system designed to provide users with useful real-time train information through a clean and modern interface.



The application allows users to search for a train using its train number and view information such as:



\- 📍 Current train location

\- 🚉 Current station

\- 🚆 Next station

\- ⏱️ Total journey duration

\- 🏁 Maximum speed

\- ⏰ Train delay

\- 📊 Journey progress

\- 🗺️ Live route map

\- 📅 Journey date

\- 🎯 Expected / Actual arrival time

\- 🏢 Station-wise timing

\- 🛤️ Complete train route

\- 🚉 Platform information



The project combines a modern frontend with a Node.js backend and railway data services to provide a practical train-tracking experience.



\---



\# ✨ Features



\## 🚆 Train Search



Search for a train using its \*\*5-digit train number\*\* and selected journey date.



\---



\## 📍 Live Train Location



Displays the train's current position on an interactive map.



The map provides:



\- Current train position

\- Previous station

\- Current station

\- Next station

\- Train route

\- Railway route visualization



\---



\## ⏱️ Live ETA



RailTrack provides estimated arrival information for the upcoming station.



The system can display:



\- Expected arrival

\- Scheduled arrival

\- Actual arrival

\- Station departure

\- Platform information



When actual arrival information becomes available, the interface prioritizes the \*\*actual arrival time\*\*.
